# Favicons

Place favicon and app icon files in this folder.

## Recommended files

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png` (180x180)
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `site.webmanifest`

## Notes

- Use the icon-only logo for favicon exports.
- Make sure the icon remains recognizable at very small sizes.
