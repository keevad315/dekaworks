# Images

Store website/app images in this folder.

## Suggested structure

- `hero/` → homepage hero images
- `portfolio/` → project/case-study visuals
- `team/` → team photos or profile graphics
- `social/` → Open Graph/Twitter sharing images

## Recommended naming

Use lowercase and hyphens:

- `hero-app-preview.png`
- `portfolio-floarte-1.png`
- `og-cover.png`

## Optimization

- Compress images before upload.
- Prefer modern formats when possible (WebP/AVIF), with PNG/JPG fallbacks if needed.
