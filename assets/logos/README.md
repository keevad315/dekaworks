# Logos

Put your brand logo files in this folder.

## Recommended files

- `logo-dark.png` → for dark backgrounds (header/hero/footer)
- `logo-light.png` → for light backgrounds
- `logo-icon.png` → icon-only version (square)

## Optional SVG versions (preferred when available)

- `logo-dark.svg`
- `logo-light.svg`
- `logo-icon.svg`

## Suggested dimensions

- Horizontal logos: at least 1200px wide
- Icon-only logo: 512x512 or higher

## Notes

- Keep transparent backgrounds where possible.
- Use short, consistent names to make wiring in HTML/CSS easy.
